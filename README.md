# Henning Peleikis — online CV

Source of my CV website, served with GitHub Pages at https://henningpeleikis.github.io.

- `index.html` — the page (no frameworks, no tracking, self-hosted font)
- `cv.pdf` — printable two-page version, generated from the same page (print stylesheet)
- `fonts/` — Schibsted Grotesk, SIL Open Font License

To regenerate the PDF after editing: open `index.html` in Chrome or Edge → Print → Save as PDF (A4, background graphics on), or run
`msedge --headless --print-to-pdf=cv.pdf --no-pdf-header-footer index.html`.
